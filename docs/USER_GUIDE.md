# Matcher 朋友试用指南

这是一份从邀请码进入到查看岗位结果的快速说明。整个流程通常是：

**邀请码登录 → 上传简历 → 设置搜索条件 → Boss App 扫码 → 查看 AI 匹配结果。**

## 1. 使用邀请码进入

打开收到的邀请链接；如果页面没有自动填写邀请码，就把 8 位邀请码粘贴到入口页并点击 **Enter**。

邀请码只能使用一次。首次进入成功后，登录状态会保存在当前浏览器中，请尽量固定使用同一台设备和浏览器，也不要主动清除本站 Cookie。邀请码已经使用后，不能再拿它登录另一台设备。

## 2. 上传简历

点击左侧 **Résumé** 卡片，上传 PDF 或 DOCX 简历，文件不要超过 5 MB。

- 上传成功后卡片会显示简历名称。
- 简历用于和岗位 JD 做匹配评分。
- 简历会在 24 小时后自动过期；过期后重新上传即可。

## 3. 免费试用与模型 Key

新用户可以先完成 **3 次成功搜索**，由站方承担模型调用。失败、取消或扫码超时不会扣次数。

三次用完后，需要在左侧 **Model Key** 中配置自己的 API Key。推荐使用 DeepSeek，步骤如下：

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/sign_up) 注册或登录账号。
2. 进入 [充值页面](https://platform.deepseek.com/top_up)，按自己的使用需要充值少量余额。
3. 打开 [API Keys 页面](https://platform.deepseek.com/api_keys)，创建一个新的 API Key。
4. 创建后立即复制以 `sk-` 开头的 Key，并妥善保存；不要发送给其他人。
5. 回到 Matcher，在 **Provider** 中选择 `DeepSeek · 推荐`，粘贴 Key，点击 **验证并保存**。

页面只会回显 Key 的末四位。完整 Key 会加密保存，不会再次显示。

## 4. 发起岗位搜索

填写岗位关键词、城市和抓取数量，然后点击 **Begin search**。

第一次搜索，或者 Boss 登录状态过期时，页面会显示登录二维码：

1. 打开手机上的 **Boss 直聘 App**。
2. 在 App 首页点击右上角 **“+” → “扫一扫”**。
3. 扫描网页中显示的二维码，并在手机上确认登录。

必须使用 Boss 直聘 App 扫码，微信扫一扫无效。登录成功后页面会自动继续抓取和 AI 分析，不需要再次点击搜索。

## 5. 查看结果

任务完成后，岗位会按 AI 匹配分数从高到低排列：

- **达标岗位**：只看达到当前分数门槛的岗位。
- **全部岗位**：查看本次分析过的所有岗位。

AI 评分适合用来确定阅读和投递顺序，不代表岗位方的正式评价。投递前仍建议打开岗位原页面核对职责、薪资和公司信息。

## 常见问题

### 扫码超时或二维码失效怎么办？

重新发起搜索即可。二维码会自动刷新；如果任务仍显示进行中，刷新网页也会自动接回当前任务，请不要连续重复点击搜索。

### 页面提示“Key 验证超时”怎么办？

这通常是 DeepSeek 验证接口暂时响应较慢，不代表 Key 错了。稍等片刻后再次点击 **验证并保存**。

### 页面提示“Key 验证失败”或“API Key 已失效”怎么办？

确认复制的是 DeepSeek 开放平台创建的完整 Key，并检查账户是否还有可用余额。必要时删除旧 Key，在 DeepSeek 平台重新创建后再保存。

### 为什么搜索失败后试用次数没有减少？

只有真正完成并成功保存结果的站方 Key 搜索才会计数。扫码超时、网络失败、取消任务都不会消耗试用次数。

### 刷新页面后任务还在吗？

还在。页面会自动接回当前运行中的任务；如果正在等待扫码，二维码会在几秒内重新出现。
